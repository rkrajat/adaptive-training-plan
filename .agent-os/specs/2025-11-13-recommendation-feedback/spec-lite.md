# Recommendation Feedback Collection - Lite Summary

A modal-based feedback system that captures user ratings (1-5), follow intent (yes/no), and optional comments for AI-generated training recommendations. Enables runners to quickly share structured feedback to help improve future recommendations and validate recommendation quality.

## Key Points
- Three-dimensional feedback: usefulness rating, intent to follow, and free-text comments
- Modal dialog triggered by button click on recommendation view
- Prevents duplicate submissions and stores feedback linked to specific recommendation and user
